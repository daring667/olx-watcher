# OLX → Telegram Watcher

Бот обходит все страницы выдачи OLX, запоминает уже встреченные объявления и отправляет в Telegram только новые совпадения: фото, цену, описание и ссылку. Под каждым уведомлением есть кнопки **«Интересует»** и **«Не интересует»**.

## Первый запуск

1. Установите Python 3.10+.
2. В терминале в папке проекта выполните:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env
   cp config.example.yaml config.yaml
   ```

3. В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте имя и username. Скопируйте токен в `.env` в строку `TELEGRAM_BOT_TOKEN`.
4. Откройте созданного бота, нажмите **Start** или отправьте ему любое сообщение. Затем выполните `python get_chat_id.py` и скопируйте напечатанный `chat_id` в `.env`.
5. Откройте OLX в браузере, выставьте город, категорию «Видеокарты» и сортировку «Сначала новые». Скопируйте URL выдачи в `config.yaml`.
6. Запустите: `python olx_watcher.py`.

Первый запуск по умолчанию лишь запомнит текущую выдачу — спама из старых объявлений не будет. Все появившиеся позже подходящие предложения придут в Telegram.

Нажмите **«Интересует»**, чтобы сохранить объявление в избранное. Нажмите **«Не интересует»**, чтобы закрыть карточку: бот не пришлёт её повторно. В Telegram команда `/favorites` выводит избранные предложения от самых дешёвых к дорогим. Этот же список доступен в терминале:

```bash
python olx_watcher.py --favorites
```

Все данные, включая цену, описание, фото, ссылку, время обнаружения и выбранный статус, хранятся локально в `data/watcher.sqlite3`.

## Локальная панель

После установки обновлённых зависимостей (`pip install -r requirements.txt`) запустите во втором терминале `python dashboard.py` и откройте http://127.0.0.1:5050. В панели есть таблица с ценами, моделями, продавцами, рисками, заметками и фильтром по статусу.

## Проверить фильтры без ожидания

Остановите работающий бот сочетанием `Ctrl+C` и выполните:

```bash
python olx_watcher.py --debug 10
```

Команда прочитает десять верхних объявлений в указанной выдаче и напечатает для каждого ссылку, распознанную цену, найденные ключевые слова и решение `ПОДХОДИТ` или `не подходит`. В Telegram она ничего не отправляет и базу уже увиденных объявлений не изменяет. После проверки запустите обычный режим снова: `python olx_watcher.py`.

## Фильтры

В `config.yaml` меняются город/ссылка выдачи, максимальная цена и ключевые слова. Слова ищутся и в заголовке, и в описании объявления. Секция `excluded_any_keywords` исключает комплектующие вроде кулеров, вентиляторов и водоблоков. Для нескольких разных поисков добавьте ссылки в `search_urls`.

По умолчанию `max_pages_per_search: 0`: бот проходит каждую доступную страницу рубрики до пустой. Полный обход выполняется раз в 30 минут (`poll_interval_seconds: 1800`) с небольшой паузой между страницами. Если OLX начнёт ограничивать обращения, задайте предел, например `max_pages_per_search: 20`, или увеличьте интервал.

Ошибки отдельных объявлений (например, `410 Gone`, когда продавец уже удалил объявление) не прерывают обход. Они сохраняются в `data/errors.log` и в таблице `errors` базы `data/watcher.sqlite3`, а такая карточка помечается обработанной и повторно не проверяется.

## Работа постоянно

Окно терминала должно оставаться включённым. Когда проверим, что всё приходит, можно настроить автозапуск на вашем компьютере или разместить бота на недорогом сервере — это отдельный следующий шаг.

## Если OLX отвечает 403 или captcha

Это означает, что сайт ограничил автоматические обращения. Не уменьшайте интервал: оставьте как минимум 60 секунд. В таком случае напишите мне текст ошибки/лог — переведём проверку на браузерный режим или подберём другой разрешённый способ получения выдачи.
